# 🎮 摸鱼小游戏集合

一个包含多个趣味游戏的动态网页，适合上班摸鱼或网络失效时娱乐。

## 功能特点

- ✅ 完全离线可用，无需网络连接
- ✅ 响应式设计，支持多种屏幕尺寸
- ✅ 美观的UI设计和流畅的动画效果
- ✅ 四款不同类型的游戏

## 游戏列表

### 1. 🔨 打地鼠
快速点击随机出现的地鼠，30秒内获得尽可能高的分数。

### 2. 🔢 数字猜谜
在7次机会内猜出1-100之间的随机数字。

### 3. 🎴 记忆翻牌
翻开卡片找出所有配对的表情符号，考验记忆力。

### 4. 🏓 弹球打砖块
使用挡板接球打破所有砖块，经典街机游戏。

## 使用方法

直接在浏览器中打开 `index.html` 文件即可开始游戏。

- 点击游戏卡片选择要玩的游戏
- 使用鼠标或键盘进行游戏操作
- 点击"返回游戏菜单"可以切换游戏

## 技术栈

- 纯 HTML/CSS/JavaScript
- 无需任何依赖或框架
- 支持 Chrome、Firefox、Safari、Edge 等现代浏览器

## 游戏控制

### 打地鼠
- 鼠标点击地鼠

### 数字猜谜
- 输入数字，按回车或点击按钮提交

### 记忆翻牌
- 鼠标点击卡片

### 弹球打砖块
- 键盘：← → 方向键移动挡板
- 鼠标：移动鼠标控制挡板位置
